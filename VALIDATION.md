# Verification scope

Run a normal frozen install with the pinned Node/package manager and native esbuild/workerd scripts, then check/build and native Wrangler dry-run. Inspect the actual linked CSS/assets, both locale FAQs and metadata, sitemap, localized true404GET/HEAD, canonical redirects, menu and analytics choice transitions. Do not treat a lock-only install or historical successful deploy as a fresh candidate test.

A local Worker preview does not establish production domain/access behavior, genuine mobile visual layout or complete analytics network blocking. Any403must be retained as a boundary rather than bypassed. Production, browser and independent acceptance gates remain separate from local source validation.
